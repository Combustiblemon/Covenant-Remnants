# Covenant Remnants

This is a starsector mod that adds covenant ships from Halo into the game.

## Contribution Guide

### Getting Started

1. Clone the repository
2. Open the project in IntelliJ IDEA
3. Run the project
4. Build the mod
5. ???
6. Profit

### Code Style

We use Kotlin for the code.

For any rendering we try to use openGL shaders whenever possible. 

There is a sample shader in the `src/org/combustiblelemon/covenantremnants/utils/render/MinimalShader.kt` file.

For a more complex shader, see the `src/org/combustiblelemon/covenantremnants/utils/render/ShieldShader.kt` file.
